# Agent tools

Generated by `scripts/render_tools_doc.py` from `backend/app/tools.py`.
A test fails if this file is out of date.

Rule for every tool: the model may pick a read-only step or write wording, and plain
code validates and runs it. No tool lets the model set a price or see the budget.

## Clarify loop (runs inside the agent)

| tool | chosen by | what it does | input | output | limits |
|---|---|---|---|---|---|
| `get_listing` | The model, one step at a time | Read the item details the user pasted (title, description, category). | None: it reads this negotiation's own listing. | The listing as JSON, or a note that there is none. | Read-only. Output cut to 1500 characters. |
| `get_market_stats` | The model, one step at a time | Summarise the similar-item prices the user supplied. | None: it reads this negotiation's own comparables. | A one-line summary, or a note that there are no comparable prices. | Read-only and informational: it never changes a price. Output cut to 1500 characters. |
| `search_knowledge` | The model, one step at a time | Look up buying guidance for this kind of item in the knowledge base. | A short text query. The search covers the item's category plus general guidance. | The best matching passages joined into one text, or a note that none were found. | Read-only vector search. Needs the knowledge base; otherwise it says so. Output cut to 1500 characters. |
| `ask_seller` | The model, one step at a time | Send the seller one short question instead of an offer this turn. | The question text. | The question becomes the draft and goes through the same message checks as every message. A rejected question is replaced by a plain template. | At most 2 questions per negotiation. Only when the seller gave no price or changed the terms. The prompt forbids numbers, budgets and limits in a question. |
| `proceed` | The model, one step at a time | Stop planning. The buyer's normal reply is written next. | None. | None. | At most 4 planning steps per turn, then planning stops by itself. |

## Calendar port (separate MCP server)

| tool | chosen by | what it does | input | output | limits |
|---|---|---|---|---|---|
| `propose_slots` | Plain code, never the model | List free pickup times. | How many slots, and optionally a start time. | ISO times: hourly slots from 10:00 to 19:00 Malaysia time, at least 24 hours ahead. | Read-only. |
| `book_slot` | Plain code, never the model | Book a pickup time after a deal. | A booking key (the run id plus ':pickup'), the run id and the start time. | booked, already_booked, slot_taken or invalid. | Idempotent: the same key never books twice. A booking failure never undoes the deal. |
| `cancel_booking` | Plain code, never the model | Cancel the pickup booked for a negotiation. | The booking key. | cancelled or not_found. | Only reachable from the user's own action in the app. |
